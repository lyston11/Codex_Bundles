# Anti-Sameness Protocol

The goal is not to promise absolute originality. The goal is to prevent the most common failure: producing a polished version of a familiar category ad.

## Before Ideation

Create a short "do not repeat" list:

```text
Category cliches:
- ...

Conversation memory:
- Routes already used:
- Visual motifs already used:
- End frames already used:
- Emotional tones already used:

Forbidden for this round:
- ...
```

## Context Contamination Firewall

When a user rejects a draft and asks to rewrite, the latest user request is the only active brief. Previous drafts become negative examples unless the user explicitly says to keep something.

Do this before ideation:

```text
Latest active brief:
Previous rejected route:
Stale-context residue to quarantine:
- setting:
- protagonist:
- visual motifs:
- metaphors:
- product demonstration:
- emotional engine:
- color / light world:
- end frame:
Allowed to keep because user repeated it:
- ...
Forbidden this round:
- ...
```

If the latest request only says "write another milk powder script", do not keep the prior forest, original forest, organic, sunlight, moss, stream, wooden table, light-frame, audit, calibration, future witness, channel-switching, or any other prior route motif. Generate from the category and current ask, not from stale context.

Hard rule: after "同质化", "没创意", "还是不行", or "重新写", at least four of these must change from the rejected draft:

- Setting
- Protagonist / POV
- Visual device
- Product demonstration method
- Emotional contradiction
- Story structure
- Sound device
- End-frame logic

If the user is continuing a campaign, preserve the brand platform but change at least two of:

- Protagonist
- World rule
- Visual metaphor
- Emotional contradiction
- Scene structure
- Product demonstration method
- End-frame twist
- Social behavior / ritual

## Cliche Detection

Flag and avoid these unless deliberately subverted:

| Category | Overused creative reflex |
| --- | --- |
| Baby / parenting | Perfect smiling baby, anxious parent saved by product, growth montage, white clinical lab proof, night-feeding soft light, future letters, memory diary, glowing particles, "every small choice becomes tomorrow" warmth. |
| Food / beverage | Slow-motion pour, exaggerated freshness explosion, family dinner harmony, vague "natural" countryside. |
| Beauty / personal care | Mirror confidence reveal, before/after glow-up, ingredient particles entering skin, generic empowerment VO. |
| Tech / apps | Frictionless UI floating in air, busy person suddenly efficient, neon data streams, feature list montage. |
| Auto / mobility | Empty mountain road, city night reflections, driver as lone hero, speed without human stakes. |
| Finance / insurance | Umbrella protection metaphor, happy family future, graphs going up, "peace of mind" VO. |
| Education | Child unlocking future, ladder/stairs, teacher as guide, exam anxiety solved by platform. |
| B2B SaaS | Dashboard montage, workflow chaos to order, floating icons, "unlock productivity". |
| Luxury | Slow object macro, anonymous elegant hands, empty marble space, heritage VO without tension. |
| Travel | Landmark montage, smiling tourists, "discover yourself", drone shot sequence. |

## Forced Divergence Matrix

When routes feel similar, force divergence across axes:

| Axis | Option A | Option B | Option C | Option D |
| --- | --- | --- | --- | --- |
| Emotional engine | Relief | Pride | Mischief | Awe |
| Story logic | Problem solved | World transformed | Secret revealed | Ritual invented |
| Scale | Tiny domestic | Social/public | Mythic/cosmic | Microscopic/internal |
| Reality | Documentary | Heightened realism | Surreal metaphor | Fable |
| Product role | Tool | Proof | Companion | Portal |
| Protagonist | User | Skeptic | Product-adjacent object | Community |
| Time | One moment | A day | Generations | Future-back |
| End frame | Pack hero | Changed behavior | Visual pun | Social invitation |

Generate routes that differ on at least four axes.

## Route Territory Reset

When the previous route is rejected for sameness, generate at least 5 territories before writing:

```text
1. Territory:
   Similarity risk to prior route:
   New device:
   Why it is product-specific:
2. ...
```

Pick the route with the lowest similarity risk that still has clear product relevance. Do not pick a route that merely changes the location while keeping the same emotional engine or proof method.

## Similarity Stress Test

Before finalizing, ask:

1. Could this be any competitor with the logo changed?
2. Have I seen this exact ad shape before?
3. Is the "big idea" just the product benefit restated?
4. Does the script rely on VO to explain why it is interesting?
5. Are the key visuals generic category imagery?
6. Would the idea still be memorable without the soundtrack?
7. Does the ending reveal something, or merely show the product?
8. Am I accidentally preserving a visual noun, metaphor, or structure from a rejected draft?
9. If the previous draft was removed from memory, would this route still be the most interesting answer to the newest request?

If three or more answers are bad, discard or rebuild the concept.

## Route Mutation

If a route is strategically right but too familiar, mutate it:

- Change the hero from a person to an object, habit, place, future self, or social ritual.
- Change the proof from explanation to visible consequence.
- Change the scale from domestic to mythic, or mythic to painfully small.
- Change the structure from "problem-solution" to "mistaken assumption-reveal".
- Change the genre: courtroom, nature documentary, heist, museum tour, cooking show, weather report, instruction manual, bedtime story, sports commentary.
- Change the ending so it reinterprets the opening.

Only keep the mutated route if product clarity survives.

## Milk Powder Hard Ban List

For high-creative milk powder briefs, do not use these as the core idea:

- Night kitchen + tired mother + warm light + gentle VO.
- Letters, postcards, diaries, or gifts from the future.
- Baby grows through a soft montage into a confident child.
- Nutrition becomes glowing particles, stars, halos, ribbons, shields, or light paths.
- Lab scientist explains trust while family scenes play.
- "Every spoon is love", "every day is growth", "guarding tomorrow" as the main idea.
- Parent anxiety is solved by a reassuring product shot.
- The product is only present as a pack ending, not as the engine of the world.

Allowed only if radically subverted:

- Future self, but as an adversary, inspector, negotiator, comic witness, or impossible system.
- Growth, but not as chronological montage.
- Family tenderness, but not as the main creative device.
- Science, but dramatized through a memorable world rule, not white-coat exposition.
