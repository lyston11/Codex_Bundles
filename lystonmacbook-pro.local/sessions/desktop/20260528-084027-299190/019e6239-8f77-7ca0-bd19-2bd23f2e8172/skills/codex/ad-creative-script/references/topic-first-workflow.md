# Topic-First Workflow

Use this when the user asks for an ad script but gives only a product/category, a broad style, or asks to rewrite without specifying a new topic.

## Principle

Do not jump from product name to finished script. A product/category is not a topic. A topic is a creative territory with tension, point of view, visual world, product role, and story engine.

Without a topic-first stage, the model will overuse recent motifs and category cliches. The safe workflow is:

```text
Topic territories -> user chooses -> creative imagination routes -> user confirms -> script / storyboard / prompts
```

## What Counts As A Specific Topic

Proceed directly only if the user supplies at least one concrete creative anchor:

- Setting or event: subway, clinic, gallery opening, family group chat, school gate, factory audit, courtroom.
- Protagonist or POV: skeptical father, product seal, child inspector, store shelf, future buyer, delivery rider.
- Creative device: trial, heist, weather report, field guide, secret society, sound-only film, one continuous route.
- Product truth: organic certification, gentle formulation, fast relief, long-lasting fragrance, data intelligence.
- Style plus subject: "奶粉 + 原始森林 + 有机阳光", "巴宝莉香水 + 伦敦画廊 + 电影感".

If the user only gives a product or says "重新写一个", "再来一个", "写一条广告", or "不够有创意", use the topic-first stage.

## Topic Shortlist Output

Provide 5-8 options. Each option should include:

```text
Topic name:
One-line premise:
Audience tension:
Creative device:
Product role:
Visual memory:
Why it avoids sameness:
Risk:
```

Do not write a full script in this stage. End by asking the user to choose one or combine two.

## Topic Diversity Rules

The topic shortlist must vary across at least five axes:

- Setting: domestic / public / work / retail / institutional / outdoor / imagined-but-real.
- POV: parent / child / skeptic / object / expert / community / product-adjacent system.
- Story shape: test / pursuit / trial / reveal / ritual / mistake / social event / investigation.
- Creative device: evidence trail / counter-image / object witness / genre transplant / single constraint / public behavior / system drama.
- Product role: proof / tool / witness / standard / trigger / companion / rule.
- Tone: restrained / mischievous / tense / warm / absurd-real / premium / documentary.
- End frame: product proof / changed behavior / social ritual / visual reversal / brand line.

No two topics should share more than two of these: setting, protagonist, creative device, proof method, emotional engine, end-frame logic.

## Rewrite After Rejection

When the user rejects a draft for sameness or lack of creativity:

1. Name the stale motifs to quarantine.
2. Generate a fresh topic shortlist.
3. Make at least 4 axes change from the rejected route.
4. Do not continue into a script until the user chooses a new topic.

## Creative Imagination Stage

After the user chooses a topic, generate 3-5 route variations within that topic:

```text
Route:
Insight:
Creative leap:
Product role:
Memory asset:
Key visual:
Story engine:
Why this route is less samey:
Risk / fix:
```

Recommend one route. If the user has clearly asked to continue or has chosen a route, write the script. Otherwise ask for confirmation.

## Quality Check

Before presenting topics, ask:

1. Would these topics lead to visibly different films?
2. Could any topic be produced by swapping in a competitor? If yes, sharpen product role.
3. Is any topic just the previous route with a new location? Replace it.
4. Is there at least one topic that feels uncomfortable, counter-category, or unexpected?
5. Are there enough realistic production paths?
